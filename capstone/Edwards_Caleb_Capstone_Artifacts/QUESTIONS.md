| # | Question | Why it can't be defaulted | Where it bites |
|---|---|---|---|
| Q1 | Normalize `Prscrbr_City` spelling variants, or leave the 226 raw strings as-is? | 28 of 226 strings are variants of another string (1,856 rows, 0.48%). Normalizing changes city-level totals; not normalizing splits Grand Junction, Colorado Springs, Lone Tree, and Fort Carson across multiple rows in every city rollup. | Any city- or region-level aggregate; STATS_OUTPUT.md §7 |
| Q2 | How to treat non-municipality values in `Prscrbr_City`: `Montebello`, `Dublin`, `Apple Valley`, `Security`, `Buckley Afb`, `Fort Carson`, `Peterson Afb` / `Peterson Space Force Base`, `U S A F Academy` / `Usaf Academy` / `Usafa`. | Neighborhoods, unincorporated localities, and military installations aren't cities. | Q3 | Which regional scheme for Colorado — Scheme A (Front Range / Western Slope / Eastern Plains / Mountain), Scheme B (CDPHE Health Statistics Regions, 21), or Scheme C (rural / frontier / urban)? | Tradeoff between citability, audience recognition, and small-cell fragility. | Q4 | Assignment rule for multi-county cities (Aurora → Adams/Arapahoe/Douglas; Littleton → Arapahoe/Douglas/Jefferson; Longmont → Boulder/Weld; Westminster → Adams/Jefferson). | Only matters if Scheme B or C is chosen. Options: assign to the county holding the largest population share, assign to the county of the city seat, or split proportionally. Each is defensible; they are not equivalent. | Crosswalk construction, if built |
| Q5 | Drug classification: CMS Geography-and-Drug flags only (4 categories, 1-2 hrs), or add RxClass ATC1 (14 categories, +3-5 hrs)? | Depends on whether the analysis needs categories beyond opioid / long-acting opioid / antibiotic / antipsychotic. `PREGAME_RESEARCH.md` §3.4 recommends CMS flags first; the ATC add-on is a scope decision, not a technical one. | Drug classification scope; project time budget |
| Q6 | If ATC is used, how to assign the 199 combination products (`Gnrc_Name` containing `/`) that map to multiple ATC codes? | Options: first ingredient, ATC code of the highest-cost component, a dedicated "Combination" class, or duplicate rows across all applicable classes. Duplicating rows breaks additivity of cost. | Drug classification, if ATC is used |
| Q7 | How to repair the 110 truncated `Gnrc_Name` values (17,624 rows) and 32 truncated `Brnd_Name` values (7,985 rows), both cut at exactly 30 characters, before any external drug-name join? | Hand repair against a drug reference, fuzzy matching, or exclude and report as unclassified. | Q10 | Do the 596 rows with `Tot_Drug_Cst = $0.00` (≥11 claims, zero cost) stay in, or come out? | Zero-cost rows produce $0.00 cost-per-claim and drag any unweighted mean/average. | Q13 | Is year-over-year comparison in scope? | If so, three method changes break comparability: the August 2021 restatement of data years 2013-2019, the 2021 change in long-acting opioid identification, and the `Prscrbr_Type_Src` encoding change. | Q14 | Should the by-Provider summary file be pulled to quantify how much the ≥11-claim redaction removes from Colorado totals? | The summary tables aggregate **all** PDE data, not the redacted detail file, so their totals are the true totals. It is additional scope, so it is a decision, not an assumption. | Defensibility of any stated Colorado total; CLEANING.md Data Limitations |
